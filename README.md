# SHMTU-Automation-Resources

上海海事大学自动化专业本科学习资料与课程资源归档。

## 项目说明与使用须知

1. **资料性质定位**：
   - 本仓库及关联课程子模块收录的内容均为各学期课程练习、实验源码、课件讲义与复习笔记的**资料选集**。
   - **未验证实际可运行性与配套环境完整性**：收录内容为资料选集，未对实际运行环境与外部配套完整性进行验证，主要供学习参考与复习借鉴。
2. **教材归档说明**：
   - 为尊重版权与精简仓库，**正式出版教材不纳入新版本课程资料库**。主库当前跟踪树不再收录这些教材；本地已有历史及浅克隆边界不作改写，历史提交中可能仍包含旧教材或待审原件记录。
3. **本地状态与远端说明**：
   - 本机课程子库已在本地准备就绪。2026-10-18 企业实习与小型智能交通装置两课已按授权建库并推送至 SMU-RES；**主库未提交、未上传**，其他课程后续是否同步至远程组织需待用户审阅后另行确认。
4. **待审原件说明**：
   - 已清理 738 个获准实体原件；原始压缩包和待审原件保留在本地原始位置，用户可按需在本地查阅。
